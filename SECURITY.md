# Security

This repository is in bootstrap. No production-readiness or security-audit claim is made.

Do not disclose vulnerabilities, credentials, private source or deployment details in public issues. Use the repository's **Security → Report a vulnerability** when GitHub private vulnerability reporting is enabled. If that option is unavailable, ask for a private reporting channel without including sensitive details. No response SLA is promised.

Security-sensitive changes need adversarial tests, explicit trust boundaries, provenance review and human review before release. Only versions explicitly identified as supported in a future release policy will receive a support commitment.
