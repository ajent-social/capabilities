# Agent instructions

Read README.md and the canonical RFC in ajent-social/capabilities before changing contracts.

- Search the catalog, standard library and mature ecosystem before adding code.
- Evidence before abstraction: no hypothetical capabilities or generic framework.
- This repository is PUBLIC. Never commit private project names, source links, source hashes, paths, infrastructure identifiers, incident histories, credentials or private census documents. Do not copy private code without explicit provenance and publication clearance.
- Public evidence must be independently accessible. Private maintainer evidence must be labelled restricted and unverified by readers; never fabricate anonymous consumer counts or adoption claims.
- A proposed guarantee is not an implemented guarantee. Record actual tests and consumer verification separately.
- Keep identity authority, billing access policy, infrastructure trust and workflow permissions explicit. Fail closed at security boundaries.
- Use reviewed upstream dependencies; preserve licenses and attribution.
- Bootstrap scope: identity (including service credentials), billing, infrastructure and delivery. No speculative utilities, other-language repositories, SaaS starter or broad migrations.
- Do not auto-merge security-sensitive APIs or promote status without maintainer review and evidence. Bootstrap publication is not blanket future merge authority.
