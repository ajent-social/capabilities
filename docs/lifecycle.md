# Lifecycle

- DISCOVERED: a potentially useful boundary, not enough evidence or agreement.
- CANDIDATE: observed reuse and a proposed contract; implementation/adoption still pending.
- EXPERIMENTAL: implementation, executed tests and a verified real consumer recorded.
- STABLE: accumulated independent adoption and explicit human approval; not permitted in first extraction.
- DEPRECATED: retained for migration, with a replacement or rationale.
- REJECTED: new AMSL implementation is unjustified; document alternatives and reconsideration criteria.

Disposition is separate from maturity: INVESTIGATE, EXTRACT, REFERENCE_EXISTING or REJECT. Proposed guarantees are not delivered guarantees. Synthetic fixtures never count as consumers.
